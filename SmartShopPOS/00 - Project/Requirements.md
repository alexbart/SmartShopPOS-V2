# Requirements

## Core Requirements

- Fast, simple browser-based cashier workflow
- Multiple users, permissions, terminals, and branches
- Product catalog, sales, purchases, inventory, and payments
- Double-entry accounting with immutable posted transactions
- Traceable stock movements and audit records
- REST API, PostgreSQL, automated tests, and structured logging

## Planned Requirements

- M-Pesa integration and reconciliation
- eTIMS/tax integration behind provider boundaries
- Reporting and cloud/web management
- Local Windows hardware agent for printing and cash drawer operations

## Future Requirements

- Broader hardware support, richer branch operations, and additional provider integrations
- Operational capabilities discovered through validated retailer workflows

Implementation truth remains code, tests, migrations, and OpenAPI; the vault preserves context rather than duplicating implementation.
